# Birds Battle

Juego original en Python + Pygame.

## Ejecutar
```bash
pip install pygame
python main.py
```

Controles:
- Arrastrar con clic izquierdo: apuntar.
- Soltar clic: lanzar.
- Clic durante el vuelo: habilidad especial.
- ESC: pausa.


## Ajuste de lanzamiento
La resortera usa una potencia máxima mayor y los objetivos iniciales fueron acercados para que los lanzamientos normales lleguen con facilidad, manteniendo la trayectoria parabólica y la física.
